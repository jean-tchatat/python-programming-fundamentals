# Python Programming Fundamentals

A collection of Python programming exercises completed during my COSC 175 coursework at Towson University.

## Topics Covered

- Conditional statements (`if`, `elif`, `else`)
- Logical operators (`and`, `or`)
- While loops and sentinel-controlled input
- Numerical calculations and comparisons
- String indexing and character manipulation
- Basic input validation

## Projects

### 1. Conditional Logic Exercises
**File:** `select_lab01.py`

Ten exercises demonstrating conditional statements, including temperature classifications, identifying the largest of three numbers, and comparing characters within strings.

### 2. Numerical Processing Exercises
**File:** `Exercise07.py`

Exercises using while loops to process numerical data, calculate averages, and manage repeated operations.

### 3. Interactive Calculator
**File:** `select_lab02.py`

A menu-driven calculator supporting arithmetic operations and handling invalid selections.

## Technologies

- Python 3
- Visual Studio Code or another Python-compatible editor
